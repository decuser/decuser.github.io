---
title: Setting Up UNIX—Sixth Edition: An OpenSIMH Laboratory for Reading Lions
tags: unix research-unix v6
---

This guide reconstructs the PDP-11/40 laboratory assumed by John Lions in *A Commentary on the UNIX Operating System* using OpenSIMH and the original Sixth Edition UNIX distribution. Following Ken Thompson and Dennis Ritchie's *Setting Up UNIX—Sixth Edition*, it produces a complete, reproducible V6 installation containing the configured kernel, complete source tree, and system documentation required to read Lions against the running system he describes.

The guide rebuilds the kernel for the laboratory configuration, installs the source and documentation filesystems, creates the required device files, verifies the completed installation, and concludes by producing a restorable baseline archive. It is intended to accompany Lions' commentary and my updated and expanded edition of *UNIX Operating System Source Code Level Six*.

Together, the two works recreate the instructional environment in which Lions originally taught V6. This guide reconstructs the laboratory itself; the companion source edition preserves Lions' numbered source listing while adding file locations, indexes, cross-references, and configured-kernel symbol tables that connect the printed listing to the running system.
