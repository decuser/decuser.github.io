    m65c02: Making the Invisible Visible

    I've been spending a lot of time with the 6502 lately, first with the Apple IIe and KIM-1, and now with an emulator of my own. The project is called m65c02. It started with a simple question: what if I could see what the processor was doing, one cycle at a time?

    Running an old machine is fun. Understanding how it runs is even better. An instruction like LDA is simple enough to describe in a sentence, but that description hides the activity on the address and data buses. I wanted to get closer to the hardware, without having to attach probes to an actual board every time I had a question.

    One inspiration is Software Masters' The Visible Computer: 6502. Back in the early 1980s, it made the processor's operation something you could watch and learn from, stepping through instructions and their microsteps. I like that idea. With m65c02, I'm taking it further into the bus cycles and the surrounding hardware. The aim is the same: make the computer less mysterious by making its workings visible. The original Visible Computer manual is worth a look.
